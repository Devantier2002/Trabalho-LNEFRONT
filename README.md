# Instruções para rodar o Front

1. Clonar e Mudar para a branch novo_front, npm install e npm run dev para rodar 

2. Abrindo o Front basta Clickar no botão Chatbot CNN e no chatbot basta escolher uma foto de um óculos que ele vai tentar descobrir o material/formato do óculos

Obs: Para uma melhor experiência com o front sugiro usar algum tema #claro do navegador...
